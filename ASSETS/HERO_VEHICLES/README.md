# Hero Vehicle Assets

This directory contains approved Kustomz Hero Vehicle master artwork.

## Asset rules

- Each Hero Vehicle has a corresponding KOS asset definition in `LIBRARIES/HV/`.
- Master artwork files use the matching HV asset ID and vehicle identifier in the filename.
- Hero vehicle artwork is stored separately from the asset definition/documentation.
- Master artwork must preserve the approved vehicle appearance; no unapproved color edits or visual alterations.
- Transparent-background PNG is the required master artwork format unless a KOS asset definition specifies otherwise.
