# Hero Vehicle Assets

This directory contains approved Kustomz Hero Vehicle master artwork.

## Clean-slate HV standard

The previous HV numbering/asset set has been retired from the active production library. New Hero Vehicles start at HV-001 and follow the authoritative Nitro CRDB master-list order.

## Source

- Primary game source: CSR2 6.7.0 Main OBB + Patch OBB.
- Vehicle identity/order source: Nitro CSR2 GitHub DB `1.Cars/#AllCarCRDBs.txt`.
- The CRDB identifier is reproduced exactly in the asset filename.
- Vehicle artwork must be extracted from the game assets; AI-generated replacement artwork is not a Hero Vehicle master.

## Asset rules

- Each approved Hero Vehicle receives its own `HV-xxx_<exact CRDB>/` directory.
- The approved master PNG is `hv-xxx_<exact CRDB>.png`.
- Master artwork is a true-transparent PNG with alpha transparency and no baked background/checkerboard.
- Vehicle identity/design is preserved once approved.
- No unapproved color edits or visual alterations are permitted.
- New HV assets enter the production library only after explicit approval.
